## 7. 已知限制与运行边界

1. **深上下文单流长生成慢**（~14–30 tok/s）：超长会话适合检索/总结类（短输出），不适合长篇连续生成。
2. **满 256k 会话并发上限 10.5 路**；16×满256k 需走 B 引擎+LMCache 分流预案（已立项备忘）。
3. 引擎长时间高负载运行后 prefill 有 ~30% 劣化现象（疑 KV 池碎片，重启即复），建议低峰周重启一次。
4. 无思考模式下小数比较类陷阱题不可靠 —— agent 侧对精度敏感判断建议开启 thinking。
5. KV 密度为开源实现现状（~40–74 KB/token）；上游落地压缩存储后容量可再涨 ~7 倍，持续跟踪。
6. 单纯 4k 附近 TTFT 偏高（top-k 回退区间）。
